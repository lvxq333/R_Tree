## 🚀 使用方法

### 1. 生成 SQL 文件

```bash
node scripts/seed-enterprise-data.mjs > scripts/seed-enterprise-data.sql
```

### 2. 执行 SQL 文件

```bash
# 方式 1：使用 psql
psql -h 127.0.0.1 -p 55432 -U postgres -d skilltree -f scripts/seed-enterprise-data.sql

# 方式 2：使用 npm script（需要先配置）
npm run db:seed
```

### 3. 验证数据

```bash
# 查看员工数量
psql -h 127.0.0.1 -p 55432 -U postgres -d skilltree -c "SELECT COUNT(*) FROM employee;"

# 查看组织关系
psql -h 127.0.0.1 -p 55432 -U postgres -d skilltree -c "SELECT COUNT(*) FROM mvp_org_relation;"

# 查看账号
psql -h 127.0.0.1 -p 55432 -U postgres -d skilltree -c "SELECT username, access_role FROM app_account;"
```
